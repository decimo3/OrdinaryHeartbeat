# OrdinaryHeartbeat - A simple endpoint to log your Excel

This app create a simple root endpoint that allow post a simple json document to persist on database

I developed this project to log the execution of automation in Excel files, in PowerQuery or VBA.

The data consist of a timestamp (created_at), ip address (creator_ip), ISO-9001 identification (created_by) and revision (creator_ver).

```python
identifier: INTEGER # ID generated by database
created_at: DATETIME # Timestamp of execution
creator_ip: VARCHAR # IP address of client
created_by: VARCHAR # ISO-9001 id of document
creator_ver: VARCHAR # Revision of document
```

## Development

```sh
python -m venv venv
source venv/Scripts/activate
pip install -r requirements.txt
```
